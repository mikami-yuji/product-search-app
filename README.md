# 商品検索ツール

Excelファイルから商品データを読み込み、検索・フィルタリング・カート機能を備えたAmazonスタイルのWebアプリケーションです。

## 主な機能

### 📊 データ管理
- **Excelファイル読み込み** - .xlsx/.xlsファイルをドラッグ&ドロップまたは選択
- **データキャッシュ** - IndexedDBを使用した自動保存
- **画像フォルダ接続** - File System Access APIでローカル画像を表示

### 🔍 検索・フィルター
- **キーワード検索** - 全項目を横断検索
- **プルダウンフィルター** - 種別、重量、材質、総色数、直送先で絞り込み
- **ソート機能** - 価格順（安い/高い）、最新受注日順

### 🎨 表示機能
- **グリッドビュー** - Amazonスタイルの商品カード表示
- **テーブルビュー** - 詳細な一覧表示
- **画像ギャラリー** - 複数画像（A、B、C...）の切り替え表示
- **Web画像対応** - asahipac.co.jpからの画像取得
- **経過期間表示** - 22ヶ月以上は黄色、24ヶ月以上は赤色でハイライト

### 🛒 カート機能
- **カートに追加** - 前回注文数を初期値として設定
- **数量調整** - 100単位での増減
- **メール文章生成** - カート内容をメール用テキストに変換してコピー

### 📱 UI/UX
- **レスポンシブデザイン** - PC・タブレット・スマホ対応
- **ページネーション** - 20件ずつ表示
- **詳細モーダル** - 商品情報をセクション分けして整理表示
- **アニメーション** - スムーズなトランジション効果

## 技術スタック

- **React** - UIライブラリ
- **Vite** - ビルドツール
- **XLSX** - Excelファイル解析
- **idb-keyval** - IndexedDB操作
- **Lucide React** - アイコン
- **Cheerio & Axios** - Web画像スクレイピング（Node.js）

## セットアップ

### 必要要件
- Node.js 16以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd product-search-app

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

### Web画像取得（オプション）

```bash
# Web画像のURLを取得（asahipac.co.jp）
node fetch_images.js

# public/product_images.jsonが生成されます
```

## 使い方

1. **Excelファイルを読み込む**
   - 右上の「ファイル選択」ボタンからExcelファイルを選択
   - データが自動的にキャッシュされます

2. **顧客フォルダを接続する**（オプション）
   - 右上の「顧客フォルダ」ボタンをクリックして、顧客ごとのExcelファイルが入ったフォルダを選択します
   - 接続すると、サイドバー上部（または初期状態の画面中央）に顧客リストが表示されます
   - 「顧客名で検索...」の検索ボックスで絞り込み、クリックするだけで瞬時にデータを切り替えられます

3. **画像フォルダを接続**（オプション）
   - 右上の「画像フォルダ」ボタンをクリックして選択
   - **検索キー仕様**: **「受注№」**（例: `70456` や `1262418`）を元に画像ファイル（`.jpg`, `.jpeg`, `.png`, `.webp` 等）を紐付けて表示します（枝番 `-01`, `_01`, `-00`, `_00` やゼロ埋めにも対応）。
   - **環境別画像フォルダ仕様**:
     - **PC環境（直下一括構造）**: 選択した画像フォルダの直下に全画像ファイルが保存されている構成に対応。余計な検索処理を一切行わず、「受注№」のみでフォルダ直下から直引き（O(1)アクセス）して一瞬で表示します。
     - **スマホ環境（顧客別サブフォルダ構造対応）**: ファイル選択時に得意先別のサブフォルダ（例: `16152_トーベイ/1262418.jpg` や `10004_上六米穀/70456.jpg`）が含まれている構成に対応。選択中の顧客（`16152`等）と「受注№」を自動照合し、スマホ側でも高速表示されます。

   #### 💡 画像表示にまつわる運用・トラブルシューティングガイド
   - **画像が表示されない場合の確認チェックリスト**:
     1. **接続状態の確認**: ヘッダーのボタンが緑色の「**画像接続済**」になっているか確認してください。黒い「**画像フォルダ**」のままである場合は、再度ボタンをクリックしてフォルダを選択・許可してください。
     2. **ファイル名と受注№の一致**: 画像のファイル名が Excel データ上の **「受注№」**（例: `70456.jpg` や `1262418.jpg`）と一致しているかご確認ください。
     3. **対応拡張子**: `.jpg`, `.jpeg`, `.png`, `.webp` （大文字 `.JPG`, `.PNG` 等も対応）。
     4. **自動認識される枝番**: `-01`, `_01`, `-00`, `_00`, `-0`, `_0`, `A`, `a`, ` (1)` などの枝番や、7桁/8桁のゼロ埋め（例: `0070456.jpg`）も自動認識されます。
   - **キャッシュ削除・データリセット時**:
     - 右上の「**キャッシュ**」メニューから「**商品データおよび接続情報を削除**」または「**最新版に強制更新**」を実行すると、IndexedDB 内の画像フォルダ接続情報（`imageDirHandle`）も完全に削除され、安全な初期状態に戻ります。
   - **超大量画像（10万件超）のパフォーマンス最適化**:
     - 画像が 10万〜15万枚存在する巨大フォルダの場合でも、全ファイルをメモリに読み込まず、画面表示されている商品のみを「受注№」で直引き（O(1)アクセス）するため、ブラウザが固まらず爆速表示されます。

4. **商品を検索・フィルター**
   - 上部の検索バーでキーワード検索
   - 左サイドバーでフィルター条件を選択
   - ソートドロップダウンで並び替え

5. **表示モードを切り替え**
   - グリッドビュー: カード形式で表示
   - テーブルビュー: 一覧形式で表示

6. **商品詳細を確認**
   - 商品カードまたは行をクリック
   - モーダルで詳細情報と画像ギャラリーを表示
   - 左右ボタンで複数画像を切り替え

7. **カートに追加して注文**
   - 「カートに追加」ボタンをクリック
   - ヘッダーの「カート」ボタンでカートを表示
   - 数量を調整（+/-ボタンは100単位）
   - 「メール文章をコピー」で注文内容をコピー
   - メールソフトに貼り付けて送信

## Excelファイルの形式

以下の列を含むExcelファイルに対応しています:

- 受注№
- 種別
- タイトル
- 商品コード
- 形状
- 重量
- 材質名称
- 受注数
- 単価
- 印刷代
- 表色数
- 裏色数
- 総色数
- JANコード
- 直送先名称
- 最新受注日

## ブラウザ対応

- Chrome/Edge 86+（推奨）
- Firefox 90+
- Safari 15.4+
